# EPU Building E Network Config

This repository stores network device configuration baselines and version-controlled configuration artifacts for Building E at Electric Power University (EPU).

## Structure

- `configs/core-switch/` — core switch baseline configs
- `configs/access-switch/` — access switch configs
- `configs/firewall/` — firewall policies
- `configs/wifi-wlc/` — Wi-Fi controller settings
- `docs/` — naming conventions and change management docs

## Notes

This is a placeholder repository for network configuration management.
